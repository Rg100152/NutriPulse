# 🍏 NutriPulse – Health & Food Planner App

![NutriPulse Banner](https://images.unsplash.com/photo-1506126613408-eca07ce68773?auto=format&fit=crop&w=1200&q=80)

**NutriPulse** is a fully functional, mobile-first health tracking and personalized meal planning web application. Built as a **single-file HTML/CSS/JS** solution, it helps you log daily vitals, track calories/water/steps, and get AI‑like meal suggestions – all with a premium, modern UI.

> ✅ **Live Demo:** [https://rg100152.github.io/NutriPulse](https://rg100152.github.io/NutriPulse)

---

## ✨ Key Features

- **Dashboard Overview** – Real-time progress bars for Calories, Water, and Steps.
- **Quick Health Check-up** – Log Blood Pressure, Glucose, and Weight via modals.
- **Smart Meal Planner** – Breakfast, Lunch, Dinner with macro breakdowns (Protein, Carbs, Fat).
- **One-Click Actions** – Log meals, swap individual meals, generate a new plan, or swap all.
- **Dynamic Health Score** – Updates automatically based on your daily calorie intake.
- **Persistent Data** – All logs saved to `localStorage` (survives page refresh).
- **Premium UI** – Clean, energetic, and fully responsive (mobile-first).
